# اقتباسات — Quotes

تطبيق أندرويد عربي خفيف لعرض الاقتباسات وحفظها ومشاركتها.

## النسخة 2.0

- واجهة عربية داكنة وبسيطة.
- اقتباس عشوائي جديد.
- حفظ وإلغاء حفظ المفضلة محليًا.
- نسخ الاقتباس إلى الحافظة.
- مشاركة الاقتباس عبر تطبيقات أندرويد.
- لا يحتاج إلى إنترنت.
- بناء مستقل بدون BlackBox أو مشاريع فرعية خارج التطبيق.
- GitHub Actions يبني APK Debug ويرفعه كـ artifact.

## البناء

```bash
./gradlew :app:assembleDebug
```

الناتج:

`app/build/outputs/apk/debug/app-debug.apk`
