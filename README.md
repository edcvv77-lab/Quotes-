# Quotes-

تطبيق اقتباسات عربي بواجهة مستخدم كاملة، ويحتوي داخله على مساحة خاصة لتشغيل تطبيقات افتراضية عبر FBlackBox.

## ابدأ من هنا للمطورين

قبل تعديل المشروع اقرأ بالترتيب:

1. `docs/CURRENT_ARCHITECTURE.md` — المعمارية الفعلية الحالية ومصدر الحقيقة.
2. `docs/PROJECT_HANDOFF.md` — آخر نقطة توقف، ما تم إثباته وما لم يتم إثباته.
3. `docs/UI_REDESIGN_PLAN.md` — خطة الواجهة الحالية.
4. `docs/UPDATE_SIGNING.md` — مفتاح التحديثات والتوقيع.

الهدف الأساسي للتوافق هو **Android 11 / API 30**.

> ملاحظة: ملفات Gradle الفعالة هي ملفات Groovy (`build.gradle` / `settings.gradle`). ملفات `.kts` الموجودة قديمة ولا تمثل مسار البناء الحالي.
